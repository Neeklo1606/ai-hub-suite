
# План редизайна главной страницы

## Анализ референсов

Из приложенных скриншотов видны ключевые паттерны современного дизайна:
- **Чистая типографика**: акцент на 1-2 словах через курсив или контрастный цвет
- **Минимализм**: меньше элементов, больше воздуха
- **Компактные иконки моделей**: ряд логотипов вместо огромного текста
- **Простой CTA**: одна кнопка вместо перегруженного интерфейса

---

## Проблемы текущего дизайна

1. **Заголовок слишком громоздкий** — "100+ нейросетей в одном окне" занимает много места и выглядит тяжело
2. **Интерактивное демо перегружено** — табы, селектор модели, quick suggestions, response area создают визуальный шум
3. **Много фоновых эффектов** — 3 gradient orb с blur выглядят избыточно
4. **Отсутствует визуальный ряд моделей** — нет иконок AI-провайдеров

---

## Предлагаемые изменения

### 1. Упрощение заголовка

**Было:**
```text
100+ нейросетей  (gradient, огромный)
в одном окне     (белый)
```

**Станет:**
```text
Все нейросети  (белый)
в одном месте  (слово "одном" — gradient курсив)
```

Стиль как в референсе "Grow *your* money" — акцент курсивом на ключевом слове.

### 2. Добавление иконок моделей

Ряд иконок AI-провайдеров над заголовком (как в chadgpt.ru):
```text
[OpenAI] [Claude] [Gemini] [Midjourney] [Suno] +50
```

Круглые аватарки 32-40px в ряд с анимацией hover.

### 3. Упрощение Hero-секции

- **Убрать** интерактивное демо с табами и ответами
- **Оставить** простой input для запроса + кнопка "Попробовать"
- **Добавить** одну CTA-кнопку под заголовком

### 4. Редизайн input-блока

Минималистичный input как в GPTunnel:
```
+--------------------------------------------------+
| Спроси что угодно...                     [🎤] [→] |
+--------------------------------------------------+
```

Без табов, без селектора модели, без quick suggestions.

### 5. Упрощение фона

- Убрать 2 из 3 gradient orbs
- Оставить один центральный тонкий glow
- Добавить subtle grid pattern (опционально)

## Детали реализации

### Типографика

- Основной текст: `font-normal` (не bold)
- Акцентное слово: `italic font-serif` или gradient
- Размеры: `text-4xl sm:text-5xl md:text-6xl` (компактнее чем сейчас)

### Иконки моделей

Компонент `ModelIcons`:
```tsx
const models = [
  { name: "OpenAI", icon: "🤖" },
  { name: "Claude", icon: "🧠" },
  { name: "Gemini", icon: "✨" },
  { name: "Midjourney", icon: "🎨" },
  { name: "Suno", icon: "🎵" },
];
// + badge "+50"
```

### Упрощённый input

- Убрать: табы, селектор модели, quick suggestions, response area
- Оставить: input + voice button + send button
- Стиль: `bg-slate-800/30 border border-slate-700/50 rounded-2xl`

### Анимации

- `fade-in` для заголовка (без сложных y-transforms)
- Hover scale на иконках моделей
- Subtle glow на CTA-кнопке

---

## Примечание

Интерактивное демо с автоматическим набором текста и ответами AI будет удалено из hero-секции. Это упростит восприятие и сфокусирует пользователя на главном CTA. Демо можно переместить в отдельную секцию ниже (опционально).
